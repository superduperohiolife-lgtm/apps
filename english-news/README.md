# English News

英語ニュースの音声をカラオケ字幕つきで聞き、その回の単語・熟語リストで復習するアプリ。

## 画面
- Top：セッションを5枠表示（未登録の枠はブランク）
- News：音声再生（−5秒／＋5秒／速度切替）。スクリプトは読まれている語をハイライトし、行を自動スクロール。語や見出しをタップするとその位置から再生。画面下の字幕バーは表示／非表示を切替可
- 単語：例文・英語・意味のカード。意味は既定でぼかし表示（タップで表示）。単語の追加・書き出しも可
  - 「分かった ✓」＝レベル相応で覚えた語。「×」削除＝レベル不相応（易しすぎ等）の語。削除した語は「削除」タブから戻せる
  - 「書き出し（コピー）」→「判定をコピー」で、分かった／削除／未習得の一覧をコピーできる。次回の単語選びの調整に使う

## しくみ
- このリポジトリ（公開）にはアプリ本体のみを置く。**音声・スクリプト・単語データは置かない**
- 素材は非公開の Google Drive フォルダに `sNN.json`（スクリプト＋単語）と `sNN.mp3`（音声）で保存
- `gas/Code.gs` を Google Apps Script の Web App としてデプロイし、アプリはその URL 経由で素材を読む
- Web App の URL は合鍵にあたるため、リポジトリに書かない。初回起動時に「接続設定」へ貼り付ける（端末のブラウザ内にのみ保存）
- 一度開いたセッションの音声・データは端末内（IndexedDB）にキャッシュ。学習状況は localStorage に保存

## GAS の設定
1. Apps Script プロジェクトを作成し `gas/Code.gs` を貼り付ける
2. スクリプト プロパティ `FOLDER_ID` に素材フォルダのIDを設定
3. デプロイ → 新しいデプロイ → ウェブアプリ（次のユーザーとして実行：自分／アクセスできるユーザー：全員）

## セッションの追加
素材フォルダに `s02.json`・`s02.mp3` のように連番で置くと、Top の次の枠に表示される（アプリ側の変更は不要）。

### sNN.json の形式
```json
{
  "id": "s01", "title": "番組名など", "date": "YYYY-MM-DD", "duration": 464.5,
  "sections": [{"title": "見出し", "kind": "news", "lines": [{"w": [["単語", 開始秒], ...]}]}],
  "vocab": [{"en": "英語", "ja": "意味", "use": "例文（[[ ]]で強調）", "src": "出典"}],
  "vocabVer": 2
}
```
- `vocabVer`：単語リストを差し替えたら数字を上げる（版の目印）。習得・削除の記録は語そのものをキーに保存しているため、差し替えても同じ語の記録は残る

## 注意
- スクリプトは録音を機械で聞き取り校正したもの。人名などに誤りが残る可能性がある
- 単語の例文は学習用に作成したもので、ニュース原文の引用ではない
- 個人の学習用。素材（音声・スクリプト）を公開の場所に置かない

## アイコン・ホーム画面への追加
- `icons/` にアプリアイコン（通常用・Androidマスク用・Apple用・favicon）、`manifest.webmanifest` にホーム画面追加用の設定
- Android の Chrome：メニュー →「ホーム画面に追加」。追加後はアイコンから全画面で開く
- 接続設定はブラウザと共通の保存領域に入るため、先にブラウザで初回設定を済ませておく
